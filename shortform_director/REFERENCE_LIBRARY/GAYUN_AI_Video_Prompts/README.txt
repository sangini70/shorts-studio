[ 알아두면 좋은 것 ]

  - 화면에 글자가 나오는 프롬프트가 있어요.
    큰 글자는 잘 나오는데, 작은 글씨는 뭉개질 수 있습니다.
    작은 글자는 나중에 편집으로 얹는 편이 나아요.

  - 프롬프트 뒤쪽의 MUSIC, SOUND DESIGN 부분은 지우지 마세요.
    이 모델은 소리까지 같이 만들어 줍니다.
    지우면 모델이 알아서 채우는데, 마음에 안 들 확률이 높아요.

  - 몇몇 프롬프트 앞부분에 '참고 이미지의 화풍을 유지하라'는
    말이 나옵니다. 바로 아래에 화풍이 전부 글로 적혀 있으니
    사진 없이 문장만 넣어도 나옵니다.
    사진을 넣으면 좀 더 비슷하게 나오는 정도예요.

  - 프롬프트는 영어입니다. 번역하지 말고 그대로 쓰세요.
    한국어로 옮기면 화풍 지시가 약해집니다.


[ 프롬프트를 고쳐 쓰고 싶을 때 ]

  여기 있는 프롬프트는 전부 같은 9개 덩어리로 되어 있어요.
  덩어리는 그대로 두고 내용만 바꾸면 품질이 유지됩니다.

    1) 한 줄 선언    Create a N-second ... film.
    2) 화풍          어떤 그림처럼 보일지. NO ~ 로 아닌 것도 적기
    3) 색            쓸 색을 이름으로 정해두기
    4) 시간표        구간마다 무슨 컷·동작·글자·소리
    5) 카메라·편집   쓸 기법과 쓰지 말 기법
    6) 음악          장르 + BPM 숫자 + 악기
    7) 소리          장면마다 소리를 하나씩
    8) 일관성        컷이 바뀌어도 안 바뀔 것들
    9) 금지          STRICTLY AVOID

  쉬운 순서는 3) 색 -> 4) 시간표 -> 2) 화풍 입니다.
  1) 6) 9) 는 그대로 두는 편이 안전해요.
