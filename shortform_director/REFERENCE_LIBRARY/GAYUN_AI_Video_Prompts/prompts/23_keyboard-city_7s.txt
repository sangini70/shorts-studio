Create a 7-second surreal retro-tech editorial animation.

CORE CONCEPT:

A gigantic human finger interacts with an enormous computer keyboard.

At first it looks like a normal stylized keyboard.

But every key press physically transforms the world.

SHIFT changes gravity.
SPACE opens an enormous empty void.
ESC makes objects disappear.
ENTER resets reality.

The keyboard gradually reveals itself to be
an impossible architectural landscape.

No dialogue.

Minimal typography only where naturally printed on keyboard keys.
